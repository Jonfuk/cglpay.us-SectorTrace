# Working in this repository

The project instructions live in [`CLAUDE.md`](CLAUDE.md). Read it before
making changes — it covers what this pipeline does, the settled decisions
that are not defaults to re-litigate, and the house style.

For an agent-assigned task, also read [`agent/README.md`](agent/README.md),
the linked environment profile and the current Linear issue, including its
parent, blockers and latest handoff. Capture the actual base commit; an old
review baseline is not an instruction to reset the checkout. The issue's
execution mode determines whether the output is a report, tests, or bounded
implementation. Readiness is not production permission or human acceptance.

**`README.md` is hand-maintained. Do not rewrite, restructure, "refresh" or
otherwise edit it on your own initiative** — not for staleness, not to match
a template, not as a side effect of another task. Edit it only when a user
message in the current session explicitly asks for a change to it.
